About TaskHub

A simple and efficient task management system built with Flask.

This task management system is a web-based application designed to help users organize, track, and manage their daily tasks efficiently.

Users can create, view, update, and delete tasks, assign priorities, set due dates, and organize tasks into categories for better planning.

The application uses Flask for the backend, SQLite for the database, and HTML, CSS, and JavaScript for the frontend.

This project was developed as a COS Group 5 assignment to demonstrate frontend development, backend routing, user authentication, database management, REST APIs, and version control with GitHub.
