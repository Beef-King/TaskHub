About TaskHub

A task manager that started as a class assignment — and got a second life.

TaskHub began as a COS Group 5 assignment: a straightforward Flask and SQLite app for creating, updating, and organizing tasks. It did the job, ticked the assignment boxes, and then sat untouched for months.

When I came back to it, I didn't just want to patch it up — I wanted to rebuild it into something I'd actually want to use. The backend stayed the same at its core, but almost everything else was reworked: a full visual redesign, a proper JSON API behind the interface instead of full-page reloads for every click, and a lot of attention to making it feel like a real product rather than a homework submission.

Today, TaskHub is a task and schedule manager built around daily use. You can create tasks with categories, priorities, due dates, and recurrence, then filter, sort, and bulk-manage them from a live dashboard. Alongside tasks, a Schedule page tracks recurring routines — daily or weekly — with time-per-day targets and a progress dashboard showing how consistent you've been. Email reminders keep both tasks and routines from slipping through the cracks, and sign-in works with GitHub or Google, not just a password.

The application runs on Flask for the backend, SQLite for the database, and HTML, CSS, and JavaScript for the frontend — the same stack it started with, just used a lot more deliberately the second time around.
